# Database & Active Record Models (`Rocket\Database`)

RocketPHP includes a PDO-backed database layer, fluent Query Builder, Active Record ORM, Schema Builder, and forward-only Migrator with zero external dependencies.

---

## 1. Configuration & Drivers

Configured in [`config/database.php`](../config/database.php) via `Env`:

| Driver | Config Keys | Notes |
| :--- | :--- | :--- |
| `sqlite` (default) | `database` (defaults to `database/database.sqlite` or `:memory:`) | Fully compatible with Query Builder & Schema Builder |
| `mysql` / `mariadb` | `host`, `port` (`3306`), `database`, `username`, `password`, `charset` (`utf8mb4`) | Fully compatible |
| `pgsql` | `host`, `port` (`5432`), `database`, `username`, `password` | **Warning:** See identifier quoting limitation below |

In [`Connection::createPdoInstance()`](../src/Database/Connection.php), PDO connections are created lazily on first query with:
- `PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION`
- `PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC`
- `PDO::ATTR_EMULATE_PREPARES => false` (native prepared statements)

> **PostgreSQL Warning:** `Query\Builder` and `Schema\Blueprint` wrap table and column identifiers in backticks (`` `table` ``) rather than driver-specific quotes (`"` for PostgreSQL). Avoid `pgsql` unless you override identifier wrapping or execute raw parameterized SQL via `DB::select()`.

## 2. Direct Connections & Raw Prepared Queries

Managed by [`DatabaseManager`](../src/Database/DatabaseManager.php) (`'db'` singleton) and exposed via [`Rocket\Facades\DB`](../src/Facades/DB.php):

```php
use Rocket\Facades\DB;

// Named or default connection
$conn = DB::connection();          // ConnectionContract
$mysql = DB::connection('mysql');

// Prepared queries (typed PDO::bindValue: INT, BOOL, NULL, STR)
$users = DB::select('SELECT * FROM users WHERE status = ?', ['active']);
$user  = DB::selectOne('SELECT * FROM users WHERE id = ?', [1]);
$id    = DB::insert('INSERT INTO users (name, email) VALUES (?, ?)', ['Alice', 'a@b.com']);
$count = DB::update('UPDATE users SET status = ? WHERE id = ?', ['inactive', 1]);
$del   = DB::delete('DELETE FROM users WHERE id = ?', [1]);
$ok    = DB::statement('PRAGMA foreign_keys = ON');

// Raw SQL expression inside Query Builder
$rows = DB::table('orders')->select('id', DB::raw('COUNT(*) as total'))->groupBy('id')->get();
```

### Transactions (with Nested Savepoints)
`Connection::beginTransaction()` tracks nesting depth in `$this->transactions` and issues `SAVEPOINT trans_{N}` / `RELEASE SAVEPOINT` / `ROLLBACK TO SAVEPOINT` for nested transactions:

```php
$result = DB::transaction(function ($connection) {
    DB::table('accounts')->where('id', 1)->update(['balance' => 900]);
    DB::table('accounts')->where('id', 2)->update(['balance' => 1100]);
    return true;
});
```

## 3. Query Builder (`Rocket\Database\Query\Builder`)

Start a query with `DB::table('users')` (returns associative `array` rows):

### Filtering & Joins
- `where(string|Raw $column, mixed $operator = null, mixed $value = null, string $boolean = 'AND')` — 2-arg form defaults operator to `'='`
- `orWhere(...)`
- `whereIn(string $column, array $values)` / `whereNotIn(string $column, array $values)` (empty `$values` compiles safely to `0 = 1` or `1 = 1`)
- `whereNull(string $column)` / `whereNotNull(string $column)`
- `whereBetween(string $column, array $values)` (requires 2 values)
- `join($table, $first, $op, $second, $type = 'INNER')` / `leftJoin(...)` / `rightJoin(...)`

### Projection, Grouping, Ordering, Limits
- `select(array|string ...$columns)` / `distinct()` / `from(string $table)`
- `groupBy(string ...$columns)` (note: `$havings` exists as a property on `Builder`, but there is no `having()` method or compilation in `toSql()`)
- `orderBy(string $column, string $direction = 'asc')` / `latest($col = 'created_at')` / `oldest($col = 'created_at')`
- `limit(int $limit)` / `take(int $limit)` / `offset(int $offset)` / `skip(int $offset)`

### Execution & Aggregates
- `get(): array`, `first(): ?array`, `find(mixed $id, string $column = 'id'): ?array`
- `count(string $column = '*'): int`, `exists(): bool`
- `sum(string $column)`, `avg(string $column)`, `min(string $column)`, `max(string $column)`
- `insert(array $values): int|string` (supports single row or batch `[[...], [...]]`), `insertGetId(array $values)`
- `update(array $values): int`, `delete(): int`
- `toSql(): string`, `getBindings(): array`

## 4. Active Record ORM (`Rocket\Database\ORM\Model`)

Generate a model with:
```bash
php rocket make:model Post
```

### Model Configuration Properties
```php
<?php

declare(strict_types=1);

namespace App\Models;

use Rocket\Database\ORM\Model;
use Rocket\Database\ORM\SoftDeletes;

class Post extends Model
{
    use SoftDeletes;

    protected ?string $table = 'posts';      // Default: snake_case(shortClass) . 's'
    protected string $primaryKey = 'id';
    protected bool $incrementing = true;
    protected ?string $connection = null;    // null = default connection
    protected bool $timestamps = true;       // auto-sets created_at & updated_at
    protected array $fillable = ['user_id', 'title', 'content'];
    protected array $guarded = ['*'];
}
```
> **Crucial Rules:**
> 1. **Table Name Auto-Pluralization**: `Model::getTable()` simply appends `'s'` (`Category` -> `'categorys'`). Set `$table` explicitly for irregular plurals.
> 2. **Mass Assignment**: Default `$guarded = ['*']` and `$fillable = []` rejects all attributes in `fill()` and `create()`. Always declare `$fillable`!

### CRUD Operations
```php
// Create
$post = Post::create(['user_id' => 1, 'title' => 'Hello', 'content' => 'Body']);

// Or instantiate + save
$post = new Post();
$post->title = 'Hello'; // Direct property setting bypasses fillable
$post->save();

// Read
$all    = Post::all();               // array of Post models
$post   = Post::find(1);             // ?Post
$post   = Post::findOrFail(1);       // throws ModelNotFoundException (HTTP 404)
$active = Post::where('user_id', 1)->orderBy('created_at', 'desc')->get();

// Update (only sends dirty columns via getDirty())
$post->title = 'Updated';
$post->save();

// Delete (sets deleted_at if SoftDeletes trait used; hard deletes otherwise)
$post->delete();
```

### Relationships & Eager Loading (N+1 Prevention)
Supported relations on [`Model`](../src/Database/ORM/Model.php):
- `hasOne(string $related, ?string $foreignKey = null, ?string $localKey = null): HasOne`
- `hasMany(string $related, ?string $foreignKey = null, ?string $localKey = null): HasMany`
- `belongsTo(string $related, ?string $foreignKey = null, ?string $ownerKey = null): BelongsTo`

(`belongsToMany` and polymorphic relations are **not** implemented.)

```php
class User extends Model
{
    protected array $fillable = ['name', 'email', 'password'];

    public function posts()
    {
        return $this->hasMany(Post::class, 'user_id', 'id');
    }
}

// Lazy loading (caches in $model->relations on access)
$posts = $user->posts;

// Eager loading (executes 1 parent query + 1 WHERE IN query per relation)
$users = User::query()->with('posts')->get();
```
> **Note:** Nested eager loading (`with('posts.comments')`) and closure constraints in `with()` are **not** supported (`ModelBuilder::eagerLoadRelations()` checks `method_exists($this->model, $relationName)` directly).

### Soft Deletes (`Rocket\Database\ORM\SoftDeletes`)
Adding `use SoftDeletes;` provides:
- `delete()` sets `deleted_at = date('Y-m-d H:i:s')` and calls `save()`.
- `restore(): bool` sets `deleted_at = null` and calls `save()` (uses `$this->newQuery(withSoftDeletes: true)` internally).
- `forceDelete(): int` permanently deletes the row.
- `trashed(): bool` checks `deleted_at !== null`.

> **Known Bug/Quirk in `ModelBuilder`:** [`ModelBuilder::withTrashed()`](../src/Database/ORM/ModelBuilder.php#L51-L56) sets `$this->withTrashed = true` without removing the `whereNull('deleted_at')` added in `__construct()`, and `onlyTrashed()` adds `whereNotNull('deleted_at')` alongside `whereNull('deleted_at')`. To query trashed rows safely without modifying core, use `(new Post())->newQuery(withSoftDeletes: true)`.

## 5. Pagination (`Rocket\Database\Paginator`)

Available on both `Query\Builder` and `ORM\ModelBuilder`:

```php
$paginator = Post::query()->orderBy('id', 'desc')->paginate(perPage: 15, page: 1);

$items       = $paginator->items();
$total       = $paginator->total();
$currentPage = $paginator->currentPage();
$lastPage    = $paginator->lastPage();
$hasMore     = $paginator->hasMorePages();
```
`Paginator` implements `Countable`, `IteratorAggregate`, and `JsonSerializable` (`toArray()` returns `'data'`, `'total'`, `'per_page'`, `'current_page'`, `'last_page'`, `'has_more'`).

## 6. Migrations & Schema Builder

Create a migration:
```bash
php rocket make:migration create_posts_table
```
Run pending migrations (from `database/migrations/`, tracked in `migrations` table with batch numbers):
```bash
php rocket migrate
```

Supported [`Schema`](../src/Database/Schema/Schema.php) and [`Blueprint`](../src/Database/Schema/Blueprint.php) APIs:
- `Schema::create($table, fn (Blueprint $table) => ...)`
- `Schema::drop($table)` / `Schema::dropIfExists($table)` / `Schema::hasTable($table)`
- Column methods: `id()`, `string($col, $len = 255)`, `text($col)`, `integer($col)`, `bigInteger($col)`, `boolean($col)`, `timestamp($col)`, `timestamps()`, `softDeletes()`
- Modifiers on [`ColumnDefinition`](../src/Database/Schema/ColumnDefinition.php): `nullable()`, `default($val)`, `unique()`, `primary()`, `autoIncrement()`

> **Not Implemented:** `Schema::table()` (ALTER TABLE), foreign key constraints, composite indexes, migration rollbacks (`migrate:rollback`), and database seeders (`db:seed`).

---

## 7. Performance Considerations

- Enable query logging only when debugging (`DB::connection()->enableQueryLog()` / `getQueryLog()`), as logs accumulate in memory.
- Always use `->with('relation')` on list queries to prevent N+1 queries.
- Prefer `DB::table(...)` over Hydrated `Model` objects for bulk read-only aggregations/exports.
