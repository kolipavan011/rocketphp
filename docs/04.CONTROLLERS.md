# Controllers (`Rocket\Routing\Controller`)

Controllers live in `app/Http/Controllers/` (namespace `App\Http\Controllers`) and typically extend [`Rocket\Routing\Controller`](../src/Routing/Controller.php).

---

## 1. Creating Controllers

Generate a controller with Rocket CLI:

```bash
php rocket make:controller ProductController
```

This creates `app/Http/Controllers/ProductController.php` (if `Controller` suffix is omitted, it is appended automatically).

---

## 2. Base Class & Reusable Methods

[`Rocket\Routing\Controller`](../src/Routing/Controller.php) provides the following `public` and `protected` methods:

| Method | Visibility | Signature / Behavior |
| :--- | :--- | :--- |
| `middleware` | `public` | `middleware(string $middleware): ControllerMiddlewareOptions` — registers controller-level middleware with fluent `->only(...)` or `->except(...)` |
| `getMiddlewareForMethod` | `public` | `getMiddlewareForMethod(string $method): array` — used internally by `Router::dispatch()` |
| `json` | `protected` | `json(mixed $data = [], int $status = 200, array $headers = []): JsonResponse` |
| `response` | `protected` | `response(string $content = '', int $status = 200, array $headers = []): Response` |
| `redirect` | `protected` | `redirect(string $url, int $status = 302): RedirectResponse` |
| `view` | `protected` | `view(string $view, array $data = []): Response` — delegates to `view($view, $data)` helper |
| `validate` | `protected` | `validate(Request $request, array $rules): array` — delegates to `validate($request->all(), $rules)` |

## 3. Dependency Injection (Constructor & Method)

When `Router::dispatch()` resolves a controller action (`[MyController::class, 'show']`):

1. **Constructor DI**: The controller is instantiated via `$this->container->make($class)`. Any type-hinted class or interface in `__construct()` is autowired using cached reflection metadata (`Container::$constructorCache`).
2. **Method DI + Route Parameters**: `Container::call([$controller, $method], $parameters)` injects:
   - Route parameters by name (e.g., `$id`, `$slug`)
   - `Rocket\Http\Request` (type-hinted as `Request $request` or named `$request`)
   - Any other container-resolvable service type-hinted on the method!

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use App\Models\User;
use App\Services\AuditService;
use Rocket\Http\Request;
use Rocket\Http\Response;
use Rocket\Routing\Controller;

class UserController extends Controller
{
    public function __construct(
        protected AuditService $audit
    ) {
        // Apply 'auth' middleware only to store and destroy
        $this->middleware('auth')->only('store', 'destroy');
        // Or exclude specific actions:
        $this->middleware('throttle')->except('index');
    }

    public function index(Request $request): Response
    {
        $page = (int) $request->query('page', 1);
        $users = User::query()->paginate(15, $page);

        return $this->json($users);
    }

    public function show(int|string $id, Request $request): Response
    {
        $user = User::findOrFail($id);

        if ($request->wantsJson()) {
            return $this->json($user);
        }

        return $this->view('users.show', ['user' => $user]);
    }

    public function store(Request $request): Response
    {
        $validated = $this->validate($request, [
            'name'  => 'required|min:2|max:100',
            'email' => 'required|email',
        ]);

        $user = User::create($validated);
        $this->audit->record('user_created', $user->id);

        return $this->redirect('/users/' . $user->id);
    }
}
```

## 4. Accessing Request Data

Inside controller actions, inject `Rocket\Http\Request $request`:

| Method | Return | Description |
| :--- | :--- | :--- |
| `$request->getMethod()` / `isMethod('POST')` | `string` / `bool` | HTTP verb (handles `_method` / `X-HTTP-Method-Override` spoofing on POST) |
| `$request->getPath()` / `getUri()` | `string` | Normalized path (e.g. `/users/5`) or full raw URI |
| `$request->query(?string $key = null, mixed $default = null)` | `mixed` | Query string (`$_GET` / URL query) |
| `$request->post(?string $key = null, mixed $default = null)` | `mixed` | Form POST parameters |
| `$request->json(?string $key = null, mixed $default = null)` | `mixed` | Parsed JSON request body (`json_decode($rawBody, true)`) |
| `$request->input(?string $key = null, mixed $default = null)` | `mixed` | Merged query + post + json + attributes |
| `$request->all()` / `only(array $keys)` / `except(array $keys)` / `has(string $key)` | `array` / `bool` | Filtered merged input |
| `$request->route(?string $key = null, mixed $default = null)` | `mixed` | Matched route parameters |
| `$request->header(string $key, ?string $default = null)` | `?string` | Case-insensitive HTTP header |
| `$request->bearerToken()` | `?string` | Token after `Bearer ` in `Authorization` header |
| `$request->cookie(string $key, ?string $default = null)` | `?string` | Cookie value |
| `$request->file(string $key)` | `mixed` | Raw `$_FILES[$key]` entry (no `UploadedFile` object wrapper) |
| `$request->ip()` / `isSecure()` / `ajax()` / `wantsJson()` | `string` / `bool` | Client metadata & content negotiation |
| `$request->user()` / `setUser(mixed $user)` | `mixed` / `void` | User attached by custom auth middleware |
| `$request->session()` / `hasSession()` / `setSession(mixed $session)` | `mixed` / `bool` | Session attached to request (`null` by default unless middleware attaches it) |

## 5. Returning Responses

- **Views**: `return $this->view('home', ['title' => 'Dashboard']);`
- **JSON**: `return $this->json(['data' => $items], 201);` (sets `Content-Type: application/json; charset=UTF-8`, uses `JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE`)
- **Redirects**: `return $this->redirect('/login', 302);` (sets `Location` header + HTML meta refresh fallback)
- **Plain / HTML**: `return $this->response('<h1>Created</h1>', 201, ['X-Custom' => '1']);`
- **Cookies on Response**:
  ```php
  return $this->response('OK')->cookie('prefs', 'dark', minutes: 60, httpOnly: true, sameSite: 'Lax');
  ```
- **Implicit Conversion**: Returning an `array`, `Model`, `Paginator`, `string`, or `null` (204) is automatically normalized by `Router::toResponse()`.
