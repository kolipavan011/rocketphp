# Performance Architecture & Optimization

RocketPHP is designed for minimal bootstrap overhead, low memory allocation, and OPcache compatibility.

---

## 1. Verified Performance Mechanisms in Source Code

1. **Zero Runtime Dependencies**: [`composer.json`](../composer.json) has zero `"require"` packages (only PHP `^8.2 || ^8.3`), keeping autoload maps small.
2. **Reflection Caching in DI Container**: [`Container`](../src/Container/Container.php) analyzes constructor and method parameters via PHP Reflection only once per class/method and stores metadata statically in `Container::$constructorCache` and `Container::$methodCache`.
3. **O(1) Static Route Matching**: [`Router`](../src/Routing/Router.php) separates parameterless routes into `$this->staticRoutes[$method][$path]` for direct hash-table lookup, avoiding regex evaluation for static URLs.
4. **Compiled Views (`storage/cache/views/`)**: [`Compiler`](../src/View/Compiler.php) compiles `.rocket.php` templates into native PHP files keyed by `sha1($path)` with `filemtime()` checks, enabling OPcache to cache the compiled views directly.
5. **Non-Backtracking Component Regexes**: `Compiler::compileComponents()` uses atomic groups `(?>...)` and possessive quantifiers (`++`, `*+`) for linear O(N) tag matching without PCRE backtracking overhead.
6. **Lazy Connections & Services**:
   - `Connection::getPdo()` defers creating the `PDO` instance until the first query runs.
   - `CacheManager::store()` lazily constructs `ArrayStore` / `FileStore` only on access.
7. **Minimal Dirty Updates**: `Model::save()` inspects `$this->getDirty()` and issues `UPDATE` statements only for changed attributes (skipping SQL altogether if nothing changed).
8. **Batch Eager Loading**: `ModelBuilder::eagerLoadRelations()` loads `HasMany`, `HasOne`, and `BelongsTo` relations via `WHERE IN (...)`, reducing $N + 1$ queries to 2 queries.
9. **FastCGI Early Flush**: `Response::send()` calls `fastcgi_finish_request()` when running under PHP-FPM before `Kernel::terminate()` cleans up scoped state.
10. **Non-Leaking Scoped Services**: `Kernel::terminate()` calls `Application::flushScoped()` so `Request` and `scoped()` bindings are purged between worker requests.

## 2. Measured Host Benchmarks (`php bin/benchmark`)

Measured via [`tests/Benchmark/FrameworkBenchmark.php`](../tests/Benchmark/FrameworkBenchmark.php) on Windows (PHP 8.2.17 CLI, **OPcache disabled**):

| Benchmark Stage | Iterations | Total Time | Avg Time / Op | Throughput |
| :--- | :--- | :--- | :--- | :--- |
| **Bootstrap** (`Application` + `Kernel`) | 1,000 | 14.83 ms | 14.83 µs | 67,430 ops/s |
| **DI Container** (3-level autowiring) | 10,000 | 109.08 ms | 10.91 µs | 91,676 ops/s |
| **Route Dispatch** (parameterized `/api/users/{id}`) | 10,000 | 275.81 ms | 27.58 µs | 36,256 ops/s |
| **Middleware Overhead** (5-stage pipeline) | 5,000 | 139.66 ms | 27.93 µs | 35,801 ops/s |
| **Database Query** (SQLite `:memory:` insert+select) | 1,000 | 108.24 ms | 108.24 µs | 9,238 ops/s |
| **View Rendering** (warm compiled template) | 2,000 | 862.58 ms | 431.29 µs | 2,319 ops/s |

*(Test suite run in same session: 84 tests, 290 assertions in 6.33s, 10.00 MB peak memory).*

## 3. Production Optimization Recommendations

1. **Composer Authoritative Classmap**: Run `composer install --no-dev --optimize-autoloader --classmap-authoritative` in production (`composer.json` already enables `"optimize-autoloader": true`).
2. **Enable PHP OPcache**: Set `opcache.enable=1` in PHP-FPM/Nginx/Apache/FrankenPHP for native bytecode caching of `src/`, `app/`, and `storage/cache/views/*.php`.
3. **Avoid Unnecessary Object Hydration**: For high-volume read endpoints or reports, use `DB::table(...)->select(...)->get()` rather than hydrating `Model` objects.
4. **Use Eager Loading**: Always call `Model::query()->with('relation')->get()` when iterating over parent collections.
5. **Pre-build Frontend Assets**: Run `npm run build` and ensure `public/hot` is removed so Vite serves hashed static assets from `public/build/manifest.json`.
6. **Note on `route:cache` & `config:cache`**: As documented in [`17.KNOWN_LIMITATIONS.md`](17.KNOWN_LIMITATIONS.md), `RouteServiceProvider` and `Kernel` do not auto-load `bootstrap/cache/routes.php` or `bootstrap/cache/config.php` out of the box.
