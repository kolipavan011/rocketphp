# Common Development Recipes

Every recipe below uses verified RocketPHP classes, helpers, and conventions.

---

## 1. Creating a New Page with Layout & Component

**1) Layout** (`resources/views/layouts/app.rocket.php`):
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>@yield('title', 'RocketPHP')</title>
    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
<body>
    <main>@yield('content')</main>
</body>
</html>
```

**2) Anonymous Component** (`resources/views/components/alert.rocket.php`):
```html
@props(['type' => 'info'])

<div {{ $attributes->merge(['class' => 'alert alert-' . $type]) }}>
    {{ $slot }}
</div>
```

**3) Page View** (`resources/views/about.rocket.php`):
```html
@extends('layouts.app')

@section('title')About Us@endsection

@section('content')
    <x-alert type="success" class="mb-4">Welcome to RocketPHP!</x-alert>
@endsection
```

**4) Route** (`routes/web.php`):
```php
use Rocket\Facades\Route;

Route::get('/about', fn () => view('about'))->name('about');
```

## 2. Building a Complete CRUD Resource Module (e.g., Posts)

**1) Migration & Model**:
```bash
php rocket make:migration create_posts_table
php rocket make:model Post
php rocket make:controller PostController
```

`database/migrations/..._create_posts_table.php`:
```php
<?php

declare(strict_types=1);

use Rocket\Database\Migrations\Migration;
use Rocket\Database\Schema\Blueprint;
use Rocket\Database\Schema\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('posts', function (Blueprint $table) {
            $table->id();
            $table->string('title');
            $table->text('body');
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('posts');
    }
};
```
Run: `php rocket migrate`

`app/Models/Post.php`:
```php
<?php

declare(strict_types=1);

namespace App\Models;

use Rocket\Database\ORM\Model;

class Post extends Model
{
    protected ?string $table = 'posts';
    protected array $fillable = ['title', 'body'];
}
```

**2) Controller** (`app/Http/Controllers/PostController.php`):
```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use App\Models\Post;
use Rocket\Http\Request;
use Rocket\Http\Response;
use Rocket\Routing\Controller;

class PostController extends Controller
{
    public function index(Request $request): Response
    {
        $page = max(1, (int) $request->query('page', 1));
        $posts = Post::query()->latest()->paginate(15, $page);

        return $this->json($posts);
    }

    public function store(Request $request): Response
    {
        $validated = $this->validate($request, [
            'title' => 'required|min:3|max:150',
            'body'  => 'required|min:10',
        ]);

        $post = Post::create($validated);

        return $this->json($post, 201);
    }

    public function show(int|string $id): Response
    {
        return $this->json(Post::findOrFail($id));
    }

    public function update(int|string $id, Request $request): Response
    {
        $post = Post::findOrFail($id);
        $validated = $this->validate($request, [
            'title' => 'required|min:3|max:150',
            'body'  => 'required|min:10',
        ]);

        $post->fill($validated)->save();

        return $this->json($post);
    }

    public function destroy(int|string $id): Response
    {
        $post = Post::findOrFail($id);
        $post->delete();

        return $this->response('', 204);
    }
}
```

**3) Routes** (`routes/api.php` — automatically prefixed with `/api`):
```php
use Rocket\Facades\Route;
use App\Http\Controllers\PostController;

Route::resource('posts', PostController::class);
```

## 3. Form Processing with CSRF & Validation Handling

> Because `Kernel::handleException()` returns HTTP 422 HTML/JSON on `ValidationException` (it does not redirect back automatically), catch `ValidationException` in web form controllers if you want custom error display:

```php
use Rocket\Security\Validation\ValidationException;

public function submitForm(Request $request): Response
{
    try {
        $data = $this->validate($request, [
            'email'    => 'required|email',
            'password' => 'required|min:8',
        ]);
    } catch (ValidationException $e) {
        return $this->view('auth.login', [
            'errors' => $e->getErrors(),
        ])->status(422);
    }

    // Process $data...
    return $this->redirect('/dashboard');
}
```
Form template:
```html
<form method="POST" action="/login">
    @csrf
    <input type="email" name="email" required>
    <input type="password" name="password" required>
    <button type="submit">Sign In</button>
</form>
```

## 4. Implementing Custom Bearer Token Authentication Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use App\Models\User;
use Closure;
use Rocket\Http\Contracts\MiddlewareInterface;
use Rocket\Http\JsonResponse;
use Rocket\Http\Request;
use Rocket\Http\Response;

class AuthMiddleware implements MiddlewareInterface
{
    public function handle(Request $request, Closure $next): Response
    {
        $token = $request->bearerToken();
        if ($token === null) {
            return new JsonResponse(['error' => 'Unauthorized'], 401);
        }

        $user = User::where('api_token', hash('sha256', $token))->first();
        if ($user === null) {
            return new JsonResponse(['error' => 'Invalid token'], 401);
        }

        $request->setUser($user);

        return $next($request);
    }
}
```
Register alias `'auth'` in `AppServiceProvider::boot()` via `$kernel->setRouteMiddleware(['auth' => AuthMiddleware::class])` and access the user in controllers via `$request->user()`.

## 5. Secure File Upload into `storage/public`

First link storage once: `php rocket storage:link`.

```php
public function uploadAvatar(Request $request): Response
{
    $file = $request->file('avatar');
    if (!is_array($file) || ($file['error'] ?? UPLOAD_ERR_NO_FILE) !== UPLOAD_ERR_OK) {
        return $this->json(['error' => 'Valid file upload required.'], 422);
    }

    if (($file['size'] ?? 0) > 2 * 1024 * 1024) {
        return $this->json(['error' => 'File exceeds 2MB limit.'], 422);
    }

    $finfo = new \finfo(FILEINFO_MIME_TYPE);
    $mime = $finfo->file($file['tmp_name']);
    $allowed = ['image/jpeg' => 'jpg', 'image/png' => 'png', 'image/webp' => 'webp'];

    if (!isset($allowed[$mime])) {
        return $this->json(['error' => 'Unsupported file type.'], 422);
    }

    $dir = storage_path('public/avatars');
    if (!is_dir($dir)) {
        mkdir($dir, 0755, true);
    }

    $filename = bin2hex(random_bytes(16)) . '.' . $allowed[$mime];
    $destination = $dir . DIRECTORY_SEPARATOR . $filename;

    if (!move_uploaded_file($file['tmp_name'], $destination)) {
        return $this->json(['error' => 'Failed to save upload.'], 500);
    }

    return $this->json([
        'url' => asset('storage/avatars/' . $filename),
    ], 201);
}
```

## 6. Creating & Injecting a Reusable Service via Service Provider

1. Create `app/Services/SlugService.php`:
   ```php
   <?php

   declare(strict_types=1);

   namespace App\Services;

   class SlugService
   {
       public function slugify(string $text): string
       {
           $slug = strtolower(trim($text));
           return trim((string) preg_replace('/[^a-z0-9]+/', '-', $slug), '-');
       }
   }
   ```
2. Bind in `app/Providers/AppServiceProvider.php`:
   ```php
   public function register(): void
   {
       $this->app->singleton(\App\Services\SlugService::class);
   }
   ```
3. Inject into any Controller constructor or action method:
   ```php
   public function store(Request $request, \App\Services\SlugService $slugs): Response
   {
       $slug = $slugs->slugify((string) $request->input('title'));
       return $this->json(['slug' => $slug]);
   }
   ```

## 7. Enabling Built-In Caching (`Cache`)

1. Add `Rocket\Cache\CacheServiceProvider::class` in [`config/app.php`](../config/app.php) under `'providers'` (and optionally `$app->register(new \Rocket\Cache\CacheServiceProvider($app));` in `bootstrap/app.php` if used in CLI).
2. Use via `Rocket\Facades\Cache`:
   ```php
   use Rocket\Facades\Cache;
   use App\Models\User;

   $users = Cache::remember('users.active', 300, function () {
       return array_map(fn ($u) => $u->toArray(), User::where('status', 'active')->get());
   });
   ```

## 8. Building Extensions / Modular Features (Without Plugins)

Because RocketPHP uses Service Providers rather than a plugin system:
1. Create a provider: `php rocket make:provider BillingServiceProvider`.
2. Organize your module under `app/Modules/Billing/` (Controllers, Models, Services, Views).
3. In `BillingServiceProvider::register()`, bind services into `$this->app`.
4. In `BillingServiceProvider::boot()`, register namespaced views (`View::addPath(...)`) and module routes (`Route::group(['prefix' => 'billing'], ...)`).
5. Register `App\Providers\BillingServiceProvider::class` in `config/app.php`.
