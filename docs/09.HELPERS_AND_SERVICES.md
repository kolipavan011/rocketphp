## 2. Service Container & Bindings ([`Rocket\Container\Container`](../src/Container/Container.php))

### Container API (`ContainerInterface`)
- `bind(string $abstract, Closure|string|null $concrete = null, bool $shared = false): void`
- `singleton(string $abstract, Closure|string|null $concrete = null): void`
- `scoped(string $abstract, Closure|string|null $concrete = null): void` (purged by `flushScoped()` on `terminate()`)
- `instance(string $abstract, mixed $instance): void`
- `alias(string $abstract, string $alias): void`
- `make(string $abstract, array $parameters = []): mixed` (supports positional & named parameter overrides + static constructor reflection caching)
- `call(callable|array|string $callback, array $parameters = []): mixed` (static method reflection caching)
- `bound(string $abstract): bool`, `resolved(string $abstract): bool`
- `flushScoped(): void`, `flush(): void`

## 4. Cache Service (`Rocket\Cache`)

Implemented stores in [`src/Cache/Stores/`](../src/Cache/Stores/):
- **`ArrayStore`** (`'array'`): In-memory key-value array with `time()` TTL check.
- **`FileStore`** (`'file'`): Writes `storage/cache/data/{2-char-sha1-prefix}/{sha1}` with 10-digit expiration timestamp + PHP `serialize()` and `LOCK_EX`.

`CacheStoreInterface` methods: `get($key, $default)`, `put($key, $value, $ttl = 0)`, `has($key)`, `forget($key)`, `flush()`, `remember($key, $ttl, Closure $cb)`, `increment($key, $val = 1)`, `decrement($key, $val = 1)`.

> **Important:** Redis, Memcached, and APCu cache drivers do **not** exist (`CacheManager::createStore()` only supports `'array'` and `'file'`). And remember to register `Rocket\Cache\CacheServiceProvider` before using `Cache`.

## 5. Events, Hooks & Other Abstractions

- **Events / Hooks**: There is **no** Event Dispatcher or hook system in `src/` (confirmed by full codebase inspection). Use Service Providers or custom event classes in `app/` if event-driven decoupling is needed.
- **Utility Classes**: `Rocket\Foundation\Env`, `Rocket\Foundation\Config`, `Rocket\Database\Paginator`, `Rocket\Database\Raw`, `Rocket\View\ComponentAttributeBag`, `Rocket\View\ComponentSlot`.
