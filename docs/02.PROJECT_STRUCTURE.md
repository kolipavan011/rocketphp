## 2. Layer Ownership & Modification Rules

### Application Layer (Modify Freely)
- **`app/`**: All business logic lives here. Default generated directories include:
  - `app/Http/Controllers/` (`make:controller`)
  - `app/Http/Middleware/` (`make:middleware`)
  - `app/Models/` (`make:model`)
  - `app/Providers/` (`make:provider`)
  - `app/View/Components/` (created on demand by `make:component`)
  - `app/Console/Commands/` (created on demand by `make:command`; auto-discovered by CLI)
- **`routes/`**: Edit `web.php`, `api.php`, and `console.php` to register HTTP endpoints and closure CLI commands.
- **`config/`**: Configure environment-backed settings. Note that adding a new `config/foo.php` automatically makes `config('foo.bar')` available via `Config::loadFromDirectory()`.
- **`resources/`**: Place `.rocket.php` templates in `resources/views/`, anonymous `<x-...>` components in `resources/views/components/`, and frontend assets in `resources/css/` & `resources/js/`.
- **`database/migrations/`**: Add forward-only migrations generated with `make:migration`.
- **`tests/`**: Add Unit and Feature tests matching `phpunit.xml`.

### Bootstrap & Entrypoints (Modify Only for Global Wiring)
- **`bootstrap/app.php`**: Registers core providers, `kernel`, and `vite`. Only edit to register core-level providers (such as `Rocket\Cache\CacheServiceProvider`) before `Kernel::bootstrap()`.
- **`public/index.php`** & **`public/.htaccess`**: Front controller and Apache rewrites. Usually untouched.
- **`rocket`** & **`bin/rocket`**: CLI bootstrap scripts. Untouched.

### Framework Core (`src/`) — Read-Only by Default
- Contains the `Rocket\` namespace. Per agent rules, **do not modify `src/`** when functionality can be built in `app/` (e.g., via service providers, controllers, middleware, models, or custom services). Only modify `src/` when explicitly asked to fix a framework bug or extend core framework capabilities.

### Generated / Runtime Artifacts (Do Not Hand-Edit)
- `storage/cache/views/*.php` and `storage/cache/data/*`: Managed by `Compiler` and `FileStore`; clear with `php rocket cache:clear`.
- `bootstrap/cache/config.php` & `bootstrap/cache/routes.php`: Generated by `config:cache` and `route:cache` (note: not auto-loaded by default `Kernel` or `RouteServiceProvider`).
- `public/build/`: Built by `npm run build`.
- `public/storage`: Symlink/junction created by `php rocket storage:link`.
