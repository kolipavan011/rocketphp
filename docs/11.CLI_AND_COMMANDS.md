# CLI & Console Commands (`php rocket`)

The RocketPHP CLI is implemented in [`src/Console/Application.php`](../src/Console/Application.php) and invoked via `php rocket <command> [arguments] [options]` (or `bin/rocket`).

---

## 1. Built-In Commands

Verified in `Rocket\Console\Application::registerDefaultCommands()` and [`routes/console.php`](../routes/console.php):

### General & Server
| Command | Syntax & Options | Implementation |
| :--- | :--- | :--- |
| `list` / `--help` / `-h` | `php rocket list` | Prints ASCII banner and grouped command list |
| `serve` | `php rocket serve [--host=127.0.0.1] [--port=8000]` | [`ServeCommand`](../src/Console/Commands/ServeCommand.php) — runs `php -S host:port -t public public/index.php` |
| `inspire` | `php rocket inspire` | [`routes/console.php`](../routes/console.php) — Closure command printing a quote |

### Code Generators (`make:*`)
| Command | Syntax & Arguments / Options | Output Location |
| :--- | :--- | :--- |
| `make:command` | `php rocket make:command <Name> [--command=sig] [--description="..."]` | `app/Console/Commands/{Name}Command.php` |
| `make:controller` | `php rocket make:controller <Name>` | `app/Http/Controllers/{Name}Controller.php` |
| `make:model` | `php rocket make:model <Name>` | `app/Models/{Name}.php` |
| `make:middleware` | `php rocket make:middleware <Name>` | `app/Http/Middleware/{Name}Middleware.php` |
| `make:migration` | `php rocket make:migration <name>` | `database/migrations/{Y_m_d_His}_{name}.php` |
| `make:provider` | `php rocket make:provider <Name>` | `app/Providers/{Name}ServiceProvider.php` |
| `make:component` | `php rocket make:component <Name> [--inline] [--view]` | `app/View/Components/{Name}.php` & `resources/views/components/{kebab}.rocket.php` |

### Database & Routing
| Command | Syntax | Implementation |
| :--- | :--- | :--- |
| `migrate` | `php rocket migrate` | [`MigrateCommand`](../src/Console/Commands/MigrateCommand.php) — runs pending `database/migrations/*.php` |
| `route:list` | `php rocket route:list` | [`RouteListCommand`](../src/Console/Commands/RouteListCommand.php) — prints Method, URI, Name, Action, Middleware table |

### Cache & Compilation
| Command | Syntax | Implementation |
| :--- | :--- | :--- |
| `cache:clear` | `php rocket cache:clear` | [`CacheClearCommand`](../src/Console/Commands/CacheClearCommand.php) — deletes files inside `storage/cache/views` and `storage/cache/data` |
| `route:cache` | `php rocket route:cache` | [`RouteCacheCommand`](../src/Console/Commands/RouteCacheCommand.php) — writes `bootstrap/cache/routes.php` *(see limitations)* |
| `route:clear` | `php rocket route:clear` | [`RouteClearCommand`](../src/Console/Commands/RouteClearCommand.php) — deletes `bootstrap/cache/routes.php` |
| `config:cache` | `php rocket config:cache` | [`ConfigCacheCommand`](../src/Console/Commands/ConfigCacheCommand.php) — writes `bootstrap/cache/config.php` *(see limitations)* |
| `config:clear` | `php rocket config:clear` | [`ConfigClearCommand`](../src/Console/Commands/ConfigClearCommand.php) — deletes `bootstrap/cache/config.php` |

### Storage Linking
| Command | Syntax & Options | Implementation |
| :--- | :--- | :--- |
| `storage:link` | `php rocket storage:link [--force\|-f] [--relative\|-r]` | [`StorageLinkCommand`](../src/Console/Commands/StorageLinkCommand.php) — links `storage/public` -> `public/storage` (NTFS junction fallback on Windows) |
| `storage:unlink` | `php rocket storage:unlink` | [`StorageUnlinkCommand`](../src/Console/Commands/StorageUnlinkCommand.php) — deletes `public/storage` safely without removing `storage/public` files |

> **Commands That Do NOT Exist:** `db:seed`, `migrate:rollback`, `migrate:fresh`, `make:seeder`, `make:plugin`, `plugin:*`, `tinker`, `queue:work`.

## 2. Argument & Option Parsing (`Console\Application::parseArguments()`)

- `--key=value` -> `$options['key'] = 'value'`
- `--flag` -> `$options['flag'] = true`
- `-f` -> `$options['f'] = true`
- Positional args -> `$arguments[0]`, `$arguments[1]`, etc.

## 3. Creating Custom Commands

### Option A: Command Class (`app/Console/Commands/`)
Any class extending [`Rocket\Console\Command`](../src/Console/Command.php) in `app/Console/Commands/*.php` is automatically discovered by `Console\Application::discoverApplicationCommands()` and resolved through `$this->app->make($className)`.

```bash
php rocket make:command PruneTemp --command=temp:prune --description="Remove temp files"
```

Inside `handle(array $arguments, array $options): int`, use `Command` IO helpers:
- `$this->argument(0, 'default')`, `$this->option('force', false)`
- `$this->line($msg)`, `$this->info($msg)`, `$this->success($msg)`, `$this->warn($msg)`, `$this->error($msg)`
- `$this->table(['Col A', 'Col B'], [['1', '2']])`
- Return `0` on success, non-zero on failure.

### Option B: Closure Command (`routes/console.php`)
```php
use Rocket\Facades\Console;

Console::command('users:count', function (array $arguments, array $options) {
    $count = \App\Models\User::query()->count();
    $this->info("Total users: {$count}");
    return 0;
})->describe('Count registered users');
```
`ClosureCommand` binds `$this` to the command instance, granting access to `$this->info()`, `$this->table()`, `$this->app`, etc.

### Programmatic Execution
```php
use Rocket\Facades\Console;

$exitCode = Console::call('cache:clear');
$exitCode = Console::call('storage:link', [], ['force' => true]);
```
