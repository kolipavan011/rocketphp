# Configuration & Environment Management

RocketPHP loads environment variables via [`Rocket\Foundation\Env`](../src/Foundation/Env.php) and PHP configuration arrays via [`Rocket\Foundation\Config`](../src/Foundation/Config.php).

---

## 1. Environment Variables (`.env`)

[`Env::load(string $filePath)`](../src/Foundation/Env.php) reads `.env` at bootstrap (`Kernel::bootstrap()` and `Application::bootstrapConfig()`):
- Ignores blank lines and `#` comments.
- Strips outer `"` or `'` quotes, or unquoted `# inline comments` (`' #'`).
- Auto-casts values in `Env::parseValue()`:
  - `'true'` / `'(true)'` -> `bool true`
  - `'false'` / `'(false)'` -> `bool false`
  - `'empty'` / `'(empty)'` -> `''`
  - `'null'` / `'(null)'` -> `null`
  - Numeric strings -> `int` or `float`
- Writes to `Env::$repository`, `$_ENV`, and `putenv()`.
- Access values in config files or code using `Env::get(string $key, mixed $default = null)` (there is no global `env()` helper).

### Default `.env.example` Keys
```ini
APP_NAME=Rocketphp
APP_ENV=development
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000
APP_KEY=base64:4v7g7F9W1eM+vK3QvL/bXkL1jZ2a0B3d8C5eF7gH9jI=

DB_CONNECTION=sqlite
DB_DATABASE=database/database.sqlite

CACHE_DRIVER=file
SESSION_DRIVER=array
```

## 2. Configuration Files (`config/*.php`)

`Config::loadFromDirectory($this->app->configPath())` loads every `*.php` file in `config/`, keyed by its basename:

| File | Config Prefix | Verified Keys |
| :--- | :--- | :--- |
| [`config/app.php`](../config/app.php) | `app.*` | `name`, `env`, `debug`, `url`, `key` (`32-byte` / `base64:` for AES-256-GCM), `providers` (`array<class-string>`) |
| [`config/database.php`](../config/database.php) | `database.*` | `default` (`'sqlite'`), `connections.sqlite`, `connections.mysql`, `connections.pgsql` |
| [`config/cache.php`](../config/cache.php) | `cache.*` | `default` (`'file'`), `stores.array`, `stores.file` |

### Reading & Mutating Config at Runtime
```php
$appName = config('app.name', 'Rocketphp');
$dbDefault = config('database.default');

// Mutate in memory:
config()->set('app.debug', false);
$exists = config()->has('cache.stores.file');
```

> **Note:** Although `SESSION_DRIVER=array` appears in `.env.example` and `phpunit.xml`, there is **no** `config/session.php` file and `SessionManager` only supports in-memory array storage. Similarly, there are no logging settings (`config/logging.php`) because no Logger subsystem exists.

## 3. Debug Mode, Error Reporting & Production Settings

- **Environment Checks**: `Application::environment()` reads `Env::get('APP_ENV', 'production')`. `Application::isProduction()` checks `environment() === 'production'`.
- **Exception Rendering**: `Kernel::handleException()` checks `$this->app->isProduction()` (note: it checks `APP_ENV === 'production'`, **not** `config('app.debug')`). In production, HTTP `500` errors conceal messages, file paths, and traces.
- **PHP Error Reporting**: RocketPHP does not configure `error_reporting()`, `ini_set('display_errors', ...)`, or `set_error_handler()` in core; configure PHP `php.ini` / `display_errors = Off` in production.

### Production Configuration Checklist
1. Set `APP_ENV=production` and `APP_DEBUG=false` in `.env`.
2. Replace `APP_KEY` with a fresh cryptographically random 32-byte key (e.g., `base64:` + base64 of 32 random bytes).
3. Enable OPcache (`opcache.enable=1`, `opcache.validate_timestamps=0` when deploying immutable builds).
4. Run `npm run build` for Vite production asset manifest (`public/build/manifest.json`) and ensure `public/hot` is absent.
5. Run `php rocket storage:link` if serving `storage/public` files.
6. Note that `php rocket config:cache` writes `bootstrap/cache/config.php`, but `Kernel::bootstrap()` and `Application::bootstrapConfig()` still call `Config::loadFromDirectory()` instead of loading `bootstrap/cache/config.php` automatically.
