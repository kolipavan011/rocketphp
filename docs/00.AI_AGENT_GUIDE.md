# RocketPHP AI Agent Developer Guide

> **Critical Warning for AI Agents:** RocketPHP uses Laravel-inspired syntax in several places, **but it is NOT Laravel**. Many Laravel features (such as `auth()`, `route()`, `request()`, `session()` global helpers, `UploadedFile`, `belongsToMany`, route model binding, `DB` schema `ALTER TABLE`, persistent file/cookie PHP sessions, and `Log`/`Event` subsystems) **do not exist** or behave differently here. Always rely on this documentation and verify against `src/`.

---

## 1. What RocketPHP Is

RocketPHP (`Rocket\Foundation\Application::VERSION === '1.0.0'`) is a zero-runtime-dependency PHP 8.2+ MVC framework located in `src/` with an application skeleton across `app/`, `bootstrap/`, `config/`, `database/`, `public/`, `resources/`, and `routes/`.

Key traits verified in the codebase:
- **PSR-4 Autoloading** (`composer.json`): `Rocket\` maps to `src/`, `App\` maps to `app/`, `Rocket\Tests\` maps to `tests/`.
- **Global Helpers** loaded via Composer `files`: [`src/Foundation/helpers.php`](../src/Foundation/helpers.php).
- **DI Container**: Reflection-cached constructor & method autowiring with `bind`, `singleton`, `scoped`, and `instance` lifetimes ([`Rocket\Container\Container`](../src/Container/Container.php)).
- **Worker-ready Scoped Flushing**: `Kernel::terminate()` calls `$app->terminate()` -> `flushScoped()`, clearing request-scoped instances such as `Request`.

## 2. Architecture Overview

1. HTTP requests enter [`public/index.php`](../public/index.php).
2. [`bootstrap/app.php`](../bootstrap/app.php) creates `Rocket\Foundation\Application`, registers 5 default service providers (`RouteServiceProvider`, `ViewServiceProvider`, `DatabaseServiceProvider`, `SecurityServiceProvider`, `AppServiceProvider`), and registers `'kernel'` (`Rocket\Foundation\Kernel`) and `'vite'` (`Rocket\Foundation\Vite`).
3. `$kernel->handle(Request::capture())` runs `$kernel->bootstrap()` (loads `.env`, loads `config/*.php`, registers `config('app.providers')`, calls `$app->boot()`), binds the scoped `Request`, passes through global middleware via `Rocket\Http\Pipeline`, and dispatches to `Rocket\Routing\Router`.
4. `Router::dispatch()` matches static routes in O(1) array lookup or dynamic routes via compiled regex, resolves route/controller middleware, invokes the action through `Container::call()`, and normalizes the return value into a `Rocket\Http\Response`.
5. Exceptions are caught in `Kernel::handle()` and rendered as JSON (if `Accept` contains `/json` or `+json`) or HTML.

See [`01.ARCHITECTURE.md`](01.ARCHITECTURE.md) for sequence diagrams and deep internals.

## 4. Application Development Workflow

1. **Scaffold files** with Rocket CLI (`php rocket list` to see all commands):
   ```bash
   php rocket make:controller ProductController
   php rocket make:model Product
   php rocket make:migration create_products_table
   php rocket make:middleware AdminMiddleware
   php rocket make:provider BillingServiceProvider
   php rocket make:component Alert
   php rocket make:command SyncInventory --command=inventory:sync
   ```
2. **Define schema** in `database/migrations/*.php` using `Rocket\Database\Schema\Schema` and `Blueprint`, then run `php rocket migrate`.
3. **Configure mass assignment** on the model (`protected array $fillable = [...];`) — required because `Model::$guarded` defaults to `['*']`.
4. **Register routes** in [`routes/web.php`](../routes/web.php) or [`routes/api.php`](../routes/api.php) using `Rocket\Facades\Route`.
5. **Create templates** in `resources/views/*.rocket.php` and components in `resources/views/components/*.rocket.php`.
6. **Wire middleware & providers** if needed in [`config/app.php`](../config/app.php) and [`app/Providers/AppServiceProvider.php`](../app/Providers/AppServiceProvider.php).
7. **Test** with `.\vendor\bin\phpunit`.

## 5. Coding Conventions (Verified from Source)

- Always begin PHP files with:
  ```php
  <?php

  declare(strict_types=1);
  ```
- Follow PSR-4 namespaces (`App\...` in `app/`, `Rocket\...` in `src/`) and PSR-12 formatting.
- Use constructor property promotion, explicit parameter types, and explicit return types (`: Response`, `: void`, `: static`, `: array`, etc.).
- Use `$this->app->singleton(...)` / `bind(...)` / `scoped(...)` in `ServiceProvider::register()`.

## 6. Quick Reference: Core Tasks

### Creating Routes (`routes/web.php` or `routes/api.php`)

```php
use Rocket\Facades\Route;
use App\Http\Controllers\UserController;

Route::get('/users', [UserController::class, 'index'])->name('users.index');
Route::get('/users/{id}', [UserController::class, 'show'])->whereNumber('id')->name('users.show');
Route::post('/users', [UserController::class, 'store'])->middleware('auth');

Route::group(['prefix' => 'admin', 'middleware' => ['auth']], function () {
    Route::get('/dashboard', [AdminController::class, 'dashboard']);
});
```
> **Warning:** `routes/api.php` is automatically prefixed with `/api` and assigned middleware group `'api'` in `RouteServiceProvider::boot()`. Do **not** chain `Route::prefix('admin')->group(...)`; use `Route::group(['prefix' => 'admin'], ...)` instead (see [`03.ROUTING.md`](03.ROUTING.md)).

### Creating Controllers (`app/Http/Controllers/`)

```php
<?php

declare(strict_types=1);

namespace App\Http\Controllers;

use App\Models\User;
use Rocket\Http\Request;
use Rocket\Http\Response;
use Rocket\Routing\Controller;

class UserController extends Controller
{
    public function show(int $id, Request $request): Response
    {
        $user = User::findOrFail($id); // Throws ModelNotFoundException (404)
        return $this->view('users.show', ['user' => $user]);
    }
}
```
> **Note:** Route parameters are passed as scalars (`string` by default; `declare(strict_types=1)` requires care if type-hinting `int` unless PHP coerces numeric strings, or accept `string|int`). There is **no route model binding**.

### Interacting with Databases & Creating Models (`app/Models/`)

```php
<?php

declare(strict_types=1);

namespace App\Models;

use Rocket\Database\ORM\Model;

class Post extends Model
{
    protected ?string $table = 'posts';
    protected array $fillable = ['user_id', 'title', 'content'];

    public function user()
    {
        return $this->belongsTo(User::class, 'user_id', 'id');
    }
}
```

Query Builder & ORM usage:
```php
use Rocket\Facades\DB;
use App\Models\Post;

// Query Builder (returns arrays)
$rows = DB::table('posts')->where('user_id', 1)->orderBy('created_at', 'desc')->get();

// ORM (returns Model instances)
$posts = Post::query()->with('user')->where('user_id', 1)->get();
$post = Post::create(['user_id' => 1, 'title' => 'Hello', 'content' => 'World']);
```

### Rendering Views (`resources/views/`)

```php
return view('welcome', ['name' => 'RocketPHP']);
// or inside Controller:
return $this->view('posts.index', ['posts' => $posts]);
```
View file `resources/views/posts/index.rocket.php`:
```html
@extends('layouts.app')

@section('content')
    @foreach($posts as $post)
        <x-feature-card :title="$post->title">
            {{ $post->content }}
        </x-feature-card>
    @endforeach
@endsection
```

### Using Middleware

```php
<?php

declare(strict_types=1);

namespace App\Http\Middleware;

use Closure;
use Rocket\Http\Contracts\MiddlewareInterface;
use Rocket\Http\Request;
use Rocket\Http\Response;

class AuthMiddleware implements MiddlewareInterface
{
    public function handle(Request $request, Closure $next): Response
    {
        if (!$request->header('authorization')) {
            return new Response('Unauthorized', 401);
        }

        return $next($request);
    }
}
```
> **Crucial:** RocketPHP registers **no global, `'web'`, or `'api'` middleware out of the box** (`Kernel::$middleware`, `$middlewareGroups`, `$routeMiddleware` start empty). Wire aliases, groups, or global middlewares in `AppServiceProvider::boot()` via `$this->app->make('kernel')`.

### Validating Requests

```php
// Inside a Controller extending Rocket\Routing\Controller:
$validated = $this->validate($request, [
    'name'     => 'required|alpha|min:3|max:50',
    'email'    => 'required|email',
    'password' => 'required|min:8',
    'confirm'  => 'required|same:password',
    'role'     => 'in:admin,editor,user',
]);

// Or anywhere using the global helper or Validator class:
$validated = validate($request->all(), ['email' => 'required|email']);
```
Supported rules are ONLY: `required`, `email`, `numeric`, `integer`, `min`, `max`, `in`, `same`, `alpha`. `Validator::validate()` throws `Rocket\Security\Validation\ValidationException` (HTTP 422).

### Handling Responses

- Return a `Response` (`response('OK', 200)`), `JsonResponse` (`json(['ok' => true], 201)`), or `RedirectResponse` (`redirect('/login')`).
- Return an `array` or `JsonSerializable` (e.g., `Model`, `Paginator`) from a route/controller — `Router::toResponse()` wraps it in `JsonResponse`.
- Return a `string` — `Router::toResponse()` wraps it in `Response` (`200`).
- Return `null` (`void`) — `Router::toResponse()` returns `204 No Content`.

### Available Global Helpers ([`src/Foundation/helpers.php`](../src/Foundation/helpers.php))

- `app(?string $abstract = null, array $parameters = []): mixed`
- `config(?string $key = null, mixed $default = null): mixed`
- `e(mixed $value): string`
- `view(string $view, array $data = [], int $status = 200, array $headers = []): Response`
- `response(string $content = '', int $status = 200, array $headers = []): Response`
- `json(mixed $data = [], int $status = 200, array $headers = []): JsonResponse`
- `redirect(string $url, int $status = 302): RedirectResponse`
- `csrf_token(): string`
- `csrf_field(): string`
- `method_field(string $method): string`
- `validate(array $data, array $rules): array`
- `vite(array|string $entrypoints, ?string $buildDirectory = null): string`
- `asset(string $path): string`
- `storage_path(string $path = ''): string`
- `public_path(string $path = ''): string`

## 7. Mandatory Rules for AI Coding Agents

1. Always read `docs/00.AI_AGENT_GUIDE.md` before starting development.
2. Read relevant documentation before implementing any feature.
3. Never assume RocketPHP supports Laravel functionality or syntax.
4. Never introduce Laravel-specific helpers, facades, conventions, or dependencies unless explicitly supported.
5. Always use existing RocketPHP classes and APIs when available.
6. Follow the existing project architecture and coding conventions.
7. Do not duplicate existing framework functionality.
8. Do not modify framework core files when the same functionality can be implemented in the application layer.
9. Maintain backward compatibility.
10. Preserve existing routes, URL structures, database schemas, and application behavior unless explicitly instructed otherwise.
11. Follow security best practices.
12. Optimize for performance without sacrificing maintainability or security.
13. Avoid unnecessary third-party dependencies.
14. Check existing implementations before creating new utilities or services.
15. Update relevant documentation whenever framework APIs, architecture, or development conventions change.
16. Never invent framework methods or APIs. Verify their implementation before using them.

## 8. Common Mistakes to Avoid

1. **Calling non-existent Laravel helpers**: `env()`, `route()`, `auth()`, `session()`, `cache()`, `logger()`, `abort()`, `back()`, `old()`, `dd()` do **not** exist. Use `Rocket\Foundation\Env::get()`, `Route::url()`, `app('session')`, `Cache::get()` (after registering `CacheServiceProvider`), etc.
2. **Using `Cache` facade without registering `CacheServiceProvider`**: `Rocket\Cache\CacheServiceProvider` is NOT registered by default in `bootstrap/app.php` or `config/app.php`! Register it before calling `Cache::*` or `app('cache')`.
3. **Using `Model::create()` without defining `$fillable`**: `Model::$guarded` defaults to `['*']`, so attributes are silently dropped unless listed in `$fillable` or `$guarded` is changed.
4. **Assuming `SessionManager` persists across requests**: `Rocket\Security\Session\SessionManager` is purely in-memory (`$attributes = []`), not backed by PHP `$_SESSION` or files/cookies.
5. **Assuming `VerifyCsrfToken` or `SecureHeaders` run automatically**: `Kernel::$middleware` and `$middlewareGroups['web']` are empty by default; you must register those middlewares on `Kernel` or routes.
6. **Chaining `Route::prefix('admin')->group(...)`**: `Router::prefix()` mutates `$groupStack` directly and does not pop it or return a group registrar. Always pass `'prefix'` inside `Route::group(['prefix' => 'admin'], fn () => ...)`.
7. **Using `withTrashed()` / `onlyTrashed()` expecting `SoftDeletes` query filtering**: `ModelBuilder::withTrashed()` does not strip the constructor's `whereNull('deleted_at')`, and `onlyTrashed()` adds `whereNotNull('deleted_at')` alongside `whereNull('deleted_at')`. Use `$model->newQuery(withSoftDeletes: true)` when querying soft-deleted rows directly.
8. **Using `Route::get('/x', MyInvokableClass::class)`**: `Container::call()` only recognizes `[Class, 'method']`, `'Class@method'`, `Closure`, or already-callable values — pass `[MyInvokableClass::class, '__invoke']`.
9. **Expecting `Schema::table()` for `ALTER TABLE`, `php rocket db:seed`, or `php rocket migrate:rollback`**: Only `Schema::create()`, `drop()`, `dropIfExists()`, `hasTable()`, and forward-only `php rocket migrate` exist.
10. **Expecting `plugins/` directory or `make:plugin`**: The plugin subsystem was intentionally removed in favor of **Service Providers** (`app/Providers/` + `php rocket make:provider`).
