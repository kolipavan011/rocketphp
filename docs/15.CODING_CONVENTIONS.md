# RocketPHP Coding Conventions

These conventions are derived directly from the RocketPHP source code (`src/`, `app/`, `config/`, `routes/`, `tests/`).

---

## 1. PHP Language & File Structure

- **PHP Version**: Targets PHP `^8.2 || ^8.3` (`composer.json`).
- **Strict Types**: **Every** PHP file across `src/`, `app/`, `config/`, `routes/`, `database/`, `public/`, and `tests/` starts with:
  ```php
  <?php

  declare(strict_types=1);
  ```
- **PSR-12 Formatting**: 4-space indentation, opening braces on new lines for classes and methods, trailing commas in multiline arrays/parameters, concise PHPDoc blocks explaining non-obvious behavior and `@var` / `@return` generics where helpful.
- **Type Declarations**: Always type-hint parameters and return types (`string`, `int`, `bool`, `array`, `mixed`, `void`, `static`, union types like `int|string`, nullable `?string`). Use `static` return type for fluent setters/builders.

---

## 2. Namespaces & File Naming (PSR-4)

| Root Namespace | Directory | Examples |
| :--- | :--- | :--- |
| `Rocket\` | `src/` | `Rocket\Routing\Router` -> `src/Routing/Router.php` |
| `App\` | `app/` | `App\Http\Controllers\UserController` -> `app/Http/Controllers/UserController.php` |
| `Rocket\Tests\` | `tests/` | `Rocket\Tests\Unit\RouterTest` -> `tests/Unit/RouterTest.php` |

### Class Naming Patterns
- Controllers: `{Entity}Controller` in `app/Http/Controllers/` (extends `Rocket\Routing\Controller`).
- Middleware: `{Name}Middleware` in `app/Http/Middleware/` (implements `Rocket\Http\Contracts\MiddlewareInterface`).
- Models: Singular `PascalCase` in `app/Models/` (extends `Rocket\Database\ORM\Model`).
- Service Providers: `{Name}ServiceProvider` in `app/Providers/` (extends `Rocket\Foundation\ServiceProvider`).
- View Components: `PascalCase` in `app/View/Components/` (extends `Rocket\View\Component`); anonymous templates use `kebab-case.rocket.php` in `resources/views/components/`.
- Console Commands: `{Name}Command` in `app/Console/Commands/` (extends `Rocket\Console\Command`).
- Migrations: `YYYY_MM_DD_His_snake_case_description.php` returning an anonymous class extending `Rocket\Database\Migrations\Migration`.
- Views: `dot.notation` mapping to `resources/views/{path}.rocket.php` (kebab-case or snake_case).

## 3. OOP & Dependency Management

- **Prefer Constructor / Method DI**: Type-hint dependencies in controllers, commands, and services rather than calling `app()` deep inside domain logic.
- **Use Contracts/Interfaces When Binding**: Bind interfaces (`FooInterface::class` -> `FooService::class`) in `ServiceProvider::register()`.
- **Fluent APIs**: Chainable configuration/builder methods return `static` (or `$this`).
- **Zero External Dependencies**: Do not add Composer packages unless strictly required by the application. Leverage PHP 8.2+ standard library (`openssl`, `pdo`, `password_hash`, `json`, `mbstring`) and existing `Rocket\` classes first.

---

## 4. Security & Performance Standards

- Always define `$fillable` explicitly on `Model` subclasses (`$guarded` defaults to `['*']`).
- Always use Query Builder value bindings or `DB::select($sql, $bindings)` — never concatenate user input into SQL strings or `DB::raw()`.
- Never pass unvalidated user input as column names to `orderBy()` / `select()` / `where()` (allowlist column names first).
- Use `{{ $var }}` (auto-escaped) in `.rocket.php` views; avoid `{!! ... !!}` on untrusted input.
- Use `->with(...)` when loading collections with relationships to avoid N+1 queries.
- Never store per-request mutable state on singletons (especially important for worker runtimes). Use `scoped()` bindings for request-scoped state.

---

## 5. Testing Conventions

- Add unit tests in `tests/Unit/*Test.php` and HTTP integration tests in `tests/Feature/*Test.php`.
- Note `phpunit.xml` enforces `beStrictAboutOutputDuringTests="true"`, `failOnRisky="true"`, and `failOnWarning="true"` — wrap CLI `ConsoleApp::call()` invocations in `ob_start()` / `ob_end_clean()` (or `ob_get_clean()`) and ensure output buffers are cleanly closed!

---

## 6. Standards Proposed (Not Automatically Enforced by Tooling)

The repository does **not** currently include PHPCS, PHP-CS-Fixer, PHPStan, or Psalm in `composer.json`. PSR-12 conformance and static type hygiene must be maintained manually or verified via `php -l` and PHPUnit.
