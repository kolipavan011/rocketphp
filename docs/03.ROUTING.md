# Routing System (`Rocket\Routing`)

Routing is implemented in [`src/Routing/Router.php`](../src/Routing/Router.php), [`src/Routing/Route.php`](../src/Routing/Route.php), [`src/Routing/RouteServiceProvider.php`](../src/Routing/RouteServiceProvider.php), and exposed statically via [`Rocket\Facades\Route`](../src/Facades/Route.php).

---

## 1. Where Routes Are Loaded

In [`RouteServiceProvider::boot()`](../src/Routing/RouteServiceProvider.php), two route files are automatically loaded when the application boots:

1. **`routes/web.php`**: Wrapped in `['middleware' => 'web']` (no URI prefix).
2. **`routes/api.php`**: Wrapped in `['prefix' => 'api', 'middleware' => 'api']`.

> **Note:** Both `'web'` and `'api'` middleware groups are initialized as empty arrays `[]` in `Rocket\Foundation\Kernel`. See [`07.MIDDLEWARE.md`](07.MIDDLEWARE.md) for how to populate them.

---

## 2. Registering Routes & HTTP Methods

```php
use Rocket\Facades\Route;
use App\Http\Controllers\UserController;

Route::get('/users', [UserController::class, 'index']); // Registers GET and HEAD
Route::post('/users', [UserController::class, 'store']);
Route::put('/users/{id}', [UserController::class, 'update']);
Route::patch('/users/{id}', [UserController::class, 'update']);
Route::delete('/users/{id}', [UserController::class, 'destroy']);
Route::options('/users', fn () => '');
Route::any('/status', fn () => ['status' => 'ok']); // GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS
Route::match(['GET', 'POST'], '/form', [FormController::class, 'handle']);
```

### Supported Route Actions
`Container::call()` invokes the route action, supporting:
- **Closure**: `fn (Request $request) => json(['ok' => true])`
- **Controller tuple**: `[UserController::class, 'show']` (Controller is resolved from DI container)
- **Controller instance tuple**: `[$controllerObject, 'show']`
- **String syntax**: `'App\Http\Controllers\UserController@show'`
- **Invokable class**: Must pass `[MyInvokableController::class, '__invoke']` (passing just `MyInvokableController::class` as a string is **not** supported by `Container::call()`).

### Return Value Normalization (`Router::toResponse()`)
Route actions may return:
- `Rocket\Http\Response` (or `JsonResponse` / `RedirectResponse`) -> returned as-is
- `array` or `\JsonSerializable` (e.g. `Model`, `Paginator`) -> wrapped in `new JsonResponse($result)` (`200`)
- `null` (or `void`) -> `new Response('', 204)`
- Any scalar/stringable -> `new Response((string) $result)` (`200`)

## 3. Route Parameters & Constraints

### Required Parameters
```php
Route::get('/posts/{slug}/comments/{id}', function (string $slug, string $id) {
    return json(['slug' => $slug, 'comment_id' => $id]);
});
```
Parameter names must match `[a-zA-Z_][a-zA-Z0-9_-]*` and match `[^/]+` unless constrained.

### Optional Parameters
Optional parameters must include a leading slash before `{name?}` (compiled as `(?:/(?P<name>[^/]+))?`):

```php
Route::get('/archive/{year?}', function (string $year = '2026') {
    return "Archive: {$year}";
});
// Matches /archive AND /archive/2025
```

### Route Constraints
Fluent methods on `Rocket\Routing\Route`:
- `->where('id', '[0-9]+')` or `->where(['id' => '[0-9]+', 'slug' => '[a-z0-9-]+'])`
- `->whereNumber('id', 'postId')` — applies `[0-9]+`
- `->whereAlpha('slug')` — applies `[a-zA-Z]+`

```php
Route::get('/users/{id}', [UserController::class, 'show'])->whereNumber('id');
// GET /users/abc throws RouteNotFoundException (404)
```

### Route Model Binding
**Not implemented.** Route parameters are passed as extracted strings (`$params`). Fetch models explicitly inside the action (e.g., `User::findOrFail($id)`).

## 4. Named Routes & URL Generation

```php
Route::get('/users/{id}/posts/{postId?}', [PostController::class, 'show'])
    ->name('users.posts.show');
```

Generate URLs via the `Route` facade or injected `Router`:

```php
use Rocket\Facades\Route;

$url = Route::url('users.posts.show', ['id' => 42, 'postId' => 7]);
// "/users/42/posts/7"

$urlWithoutOptional = Route::url('users.posts.show', ['id' => 42]);
// "/users/42/posts"
```

> **Important:** There is **no** global `route()` helper function in `helpers.php`. Use `Route::url(...)`. Calling `Route::url()` with an undefined name throws `InvalidArgumentException`.

## 5. Route Groups & Prefixes

Use `Route::group(array $attributes, Closure $routes)` with `'prefix'` and/or `'middleware'` keys. Groups may be nested:

```php
Route::group(['prefix' => 'admin', 'middleware' => ['auth']], function () {
    Route::get('/dashboard', [AdminController::class, 'dashboard'])->name('admin.dashboard');

    Route::group(['prefix' => 'billing'], function () {
        Route::get('/invoices', [InvoiceController::class, 'index']); // /admin/billing/invoices
    });
});
```

> **Gotcha — Do NOT use `Route::prefix('admin')->group(...)`:** `Router::prefix(string $prefix): static` pushes onto `$this->groupStack` without popping and returns `$this` (`Router`), whose `group()` signature requires `(array $attributes, Closure $routes)`. Always use `Route::group(['prefix' => '...'], fn () => ...)`.

## 6. RESTful Resource Routes

`Route::resource(string $name, string $controller): void` registers 8 standard endpoints (returns `void`, so you cannot chain `->middleware()` directly onto `resource()`):

| Method | URI | Action | Route Name |
| :--- | :--- | :--- | :--- |
| `GET`/`HEAD` | `/{name}` | `index` | `{name}.index` |
| `GET`/`HEAD` | `/{name}/create` | `create` | `{name}.create` |
| `POST` | `/{name}` | `store` | `{name}.store` |
| `GET`/`HEAD` | `/{name}/{id}` | `show` | `{name}.show` |
| `GET`/`HEAD` | `/{name}/{id}/edit` | `edit` | `{name}.edit` |
| `PUT` | `/{name}/{id}` | `update` | `{name}.update` |
| `PATCH` | `/{name}/{id}` | `update` | *(unnamed)* |
| `DELETE` | `/{name}/{id}` | `destroy` | `{name}.destroy` |

To apply middleware to a resource, wrap it in `Route::group(['middleware' => ...], fn () => Route::resource(...))` or register middleware in the controller constructor.

---

## 7. Middleware Assignment

Attach middleware aliases, group names, or FQCNs on routes or groups:

```php
Route::post('/posts', [PostController::class, 'store'])
    ->middleware(['auth', 'csrf']);

// Multiple string arguments also work:
Route::get('/secret', fn () => 'ok')->middleware('auth', 'throttle');
```

---

## 8. Route Compilation & Caching

`Router::compile()` exports static routes, dynamic routes, and names into a pure PHP array, and `Router::loadCompiled(array $cache)` restores them. The CLI commands:
- `php rocket route:cache` writes `bootstrap/cache/routes.php`
- `php rocket route:clear` deletes `bootstrap/cache/routes.php`

> **Limitation:** [`RouteServiceProvider::boot()`](../src/Routing/RouteServiceProvider.php) does **not** currently check for or load `bootstrap/cache/routes.php` automatically; it always requires `routes/web.php` and `routes/api.php`. Furthermore, Closure actions cannot be serialized by `var_export()` in `route:cache` — route caching only works if all routes use controller array/string actions and you wire `loadCompiled()` in your provider.

---

## 9. 404 & 405 Handling

In `Router::findRoute()`:
1. Static routes in `$this->staticRoutes[$method][$path]` are checked in O(1) time.
2. Dynamic routes in `$this->dynamicRoutes[$method]` are checked sequentially using compiled regexes.
3. If no route matches for `$method`, `Router` checks all routes via `Route::matchesPath($path)`:
   - If the path exists for other HTTP methods -> throws [`MethodNotAllowedException`](../src/Routing/Exceptions/MethodNotAllowedException.php) (`getStatusCode() === 405`, `getAllowedMethods()`).
   - Otherwise -> throws [`RouteNotFoundException`](../src/Routing/Exceptions/RouteNotFoundException.php) (`getStatusCode() === 404`).

Both exceptions are caught by `Kernel::handleException()` and returned with status `404` or `405`.
